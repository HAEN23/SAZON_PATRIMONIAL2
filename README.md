# Sazón Patrimonial - Prototipo / Borrador

Este repositorio contiene la versión preliminar (borrador o prototipo inicial) del proyecto **Sazón Patrimonial**, una aplicación web orientada a servir como catálogo de restaurantes para Chiapa de Corzo. 

Este proyecto fue inicializado como punto de partida para experimentar con la estructura base, la configuración del framework y la interfaz frontend antes de consolidar la arquitectura del proyecto final.

## 🛠️ Tecnologías Utilizadas en este Borrador

Este entorno de pruebas está configurado con el siguiente stack base:

* **Framework:** [Next.js](https://nextjs.org/) (Configurado con App Router)
* **Lenguaje:** [TypeScript](https://www.typescriptlang.org/) para tipado estático seguro.
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/) (gestionado a través de PostCSS).
* **Linter:** ESLint para mantener la calidad del código.
